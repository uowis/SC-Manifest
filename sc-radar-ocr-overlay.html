Aucune zone définie — dessine un rectangle sur la source ci-dessus pour délimiter la zone des signatures radar.

La police du HUD est petite et condensée — un agrandissement ×3 à ×5 combiné à la binarisation aide beaucoup l'OCR. Augmente le seuil si l'image prétraitée ci-dessous est trop "chargée" de bruit, baisse-le si les chiffres disparaissent. La case lecture multi-seuils relance l'OCR avec trois seuils (seuil − écart, seuil, seuil + écart) et garde le résultat majoritaire — utile si la lecture est instable d'une frame à l'autre, au prix d'environ trois fois plus de calcul par cycle. Le curseur écart multi-seuils règle cet écart (±x autour du seuil principal).

Table de correspondance minéraux

Chaque ligne associe un texte/valeur lu par l'OCR à un minéral affiché dans l'overlay. Type Signature (×1) : valeur de référence pour 1 roche/objet, et max = nombre maximum de roches/objets observable pour ce minéral — l'appli cherche, pour le nombre lu, le minéral et le multiplicateur (de ×1 à max) dont base × N est le plus proche, dans une tolérance de ±6. Limiter max évite les fausses correspondances avec un minéral dont base × N coïncide pour un N trop grand. Type contient : le texte lu doit contenir ce mot (ex. nom du minéral affiché dans la composition d'une roche). Type plage : un nombre lu doit être compris entre min et max. La table par défaut est calibrée sur la 4.7 (LoudGuns) — vérifie/ajuste si le patch a changé les valeurs.
